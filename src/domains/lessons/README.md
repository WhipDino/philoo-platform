# Philoo Lessons

Before creating a lesson, read:

1. `docs/playbooks/CREATE_A_LESSON.md`
2. `docs/product/CURRICULUM_MAP.md`
3. `docs/product/PHILOO_EXERCISE_CATALOG_V1.md`
4. `docs/reference/CHARACTERS_AND_ASSETS.md`

Lessons own philosophy content, narrative, configuration, approved assets, and
transitions. Reusable engines own protected interaction and responsive
behavior. Import foundation engines through `@/domains/lesson-library`; do not
copy another lesson's renderer.
